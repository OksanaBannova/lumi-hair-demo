# LUMI HAIR — Demo

Публичное демо премиального шаблона сайта для мастера по уходу за волосами.

## ✦ Что можно посмотреть

- адаптивный лендинг;
- первый экран с Hero-блоком;
- услуги и цены;
- портфолио;
- отзывы;
- FAQ;
- контакты;
- онлайн-запись;
- мобильную версию;
- анимации и интерактивные элементы;
- сохранение части данных в LocalStorage.

## ✦ Технологии

- HTML5
- CSS3
- JavaScript
- LocalStorage
- Google Fonts

Установка npm, сборка и сервер не требуются.

## ✦ Запуск локально

Откройте `index.html` в браузере.

Для публикации через GitHub Pages достаточно загрузить содержимое этого репозитория и включить GitHub Pages для ветки `main` и папки `/root`.

## ✦ Структура

```text
LUMI-HAIR-DEMO/
├── index.html
├── style.css
├── script.js
└── README.md
```

## ✦ Важно

Это **демонстрационная версия** LUMI HAIR.

CRM, административная панель и полный комплект файлов коммерческого шаблона в публичное демо не входят.

Исходные файлы демо доступны для просмотра в рамках демонстрации продукта. Полная коммерческая версия, включая CRM и административную панель, поставляется отдельно в соответствии с лицензией продавца.

## ✦ Коммерческая версия

Полная версия предназначена для самостоятельного использования и адаптации под сайт мастера, студии или салона.

В коммерческий комплект входят дополнительные файлы и административная часть проекта.
