# LUMI HAIR — Demo

Публичная демонстрационная версия шаблона LUMI HAIR.

## Что это

Премиальный адаптивный сайт для мастера по уходу за волосами: кератиновое выпрямление, ботокс, восстановление и уход.

## В демо есть

- главная страница;
- услуги и цены;
- портфолио;
- отзывы;
- FAQ;
- контакты;
- онлайн-запись;
- адаптивная мобильная версия;
- локальное сохранение записей в браузере.

## Публичная версия

Это только demo-версия. Административная панель и CRM не публикуются в этом репозитории.

## Запуск

Откройте `index.html` локально или разместите репозиторий на GitHub Pages.

## Коммерческая версия

Полная коммерческая версия шаблона включает дополнительные файлы и административную панель. Исходные файлы коммерческой поставки не размещаются в публичном demo-репозитории.
